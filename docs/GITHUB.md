# 公开版范围与运行说明

## 仓库内容

提交内容限于源码、测试、依赖清单、设计文档、通用参数模板、静态截图与截图入口。南京客户资料与结果只保留在原本地项目。

以下内容不进入公开仓库或其历史：真实数据目录、运行目录、实验档案、客户演示HTML、本机研究配置、第三方二进制，以及南京CSV、Excel、GeoJSON或结果JSON。只在最新提交删除文件不足以清理历史，因此本公开版从新的独立Git历史建立。

## 使用流程

1. 按README安装环境并运行无客户数据的测试。
2. 按[数据契约](数据与参数契约.md)准备自己的授权单元、边界、指标、邻接、道路和候选分配。
3. 修改`configs/example.json`中的数据路径与业务参数。
4. 运行`validate`和`evaluate`，打开命令返回的`runs/.../report.html`。

`index.html`与README只展示截图，不包含隐藏的南京数据载荷。未配置GitHub Pages；可克隆后本地打开静态入口。

## 可选研究程序

只有`solve`需要本机`adapters/research.json`和兼容研究改编程序。登记结构为dataset_manifest_sha256及engines映射，每个方法提供executable、sha256和options。该文件必须留在本机，不提交。

当前后端内部固化了特定8HC、三属性容差及道路上限，并绑定特定路网；公开参数模板不意味着已支持通用求解。上游普通程序不具备本项目道路评价、共同起点和档案输出约定，不能直接替代。详见[设计文档](DESIGN.md#7-求解适配器设计)。

第三方研究代码的原许可和项目自身源码的授权是不同问题；本次未添加许可证，不据此承诺商用授权。
